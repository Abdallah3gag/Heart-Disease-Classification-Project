# 10-Year Coronary Heart Disease Risk Prediction

## Overview
This project predicts the **10-year risk of coronary heart disease (CHD)** using the **Framingham Heart Study dataset**. Early prediction helps in preventive healthcare.  



## Features
The dataset includes demographic, lifestyle, and medical measurements such as age, gender, smoking habits, blood pressure, cholesterol, BMI, and glucose. The target variable is **TenYearCHD**.  



## Preprocessing
- Handled **missing values** and **outliers**  
- Scaled continuous features  



## Models Used
- **Logistic Regression**  
- **XGBoost**  
- **MLP Classifier (Neural Network)**  




**Highlights:**  
- Logistic Regression & XGBoost: Accuracy ~85%,   
- MLP Classifier: Accuracy 80%,with higher recall for CHD = Yes
